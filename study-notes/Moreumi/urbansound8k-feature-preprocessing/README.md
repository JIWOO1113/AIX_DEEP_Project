# Bit depth(얼마나 정밀하게 기록할까)
8비트: 단순화
16비트: 거의 원본과 동일 (사람 귀로 구분 불가)
24비트: 완전히 원본과 동

| 비트 깊이 (subtype) | 파일 수 | 의미 |
|---|---|---|
| **PCM_16** | 5,758 (66%) | 16비트 정수 (CD 표준) |
| **PCM_24** | 2,753 (32%) | 24비트 정수 (고음질) |
| **FLOAT** | 169 (2%) | 32비트 부동소수점 |
| PCM_U8 | 43 | 8비트 unsigned (저음질) |
| MS_ADPCM | 8 | 압축 포맷 (오래된 Windows) |
| IMA_ADPCM | 1 | 압축 포맷 |

16/24비트가 표준. 무조건 float32 배열로 변환
librosa.load는 무조건 float32 형식으로 변환해서 반환합니다.
그래서 bit depth 통일은 별로 필요 없다.

# Channel(마이크가 몇 개인가)

스테레오(2채널) : 7,993개 (92%)
모노(1채널)    :   739개 ( 8%)

스테레오->모노 변환은 두 채널 평균 내서 처리
환경음 분류에서는 방향성 정보가 거의 무관하기 때문

다만, 음원의 공간 정보가 중요하거나 두 채널의 위상 차이가 분류 신호인 경우에는 
통일하지 않아야 한다.

# 클리핑 파일

gun_shot       : 232개 (62%가 클리핑!)
dog_bark       : 108개
engine_idling  :  71개
...

클리핑이란, <br>
소리가 너무 커서 녹음장비가 표현할 수 있는 최대 한계를 넘어버려,
파형의 꼭대기가 잘려나간 상태

판단 근거

peak = float(np.max(np.abs(y_mono)))  # 파형의 최댓값
...
"has_clipping": peak >= 0.99,         # 0.99 이상이면 클리핑 의심

클리핑 자체가 그 소리의 특징이라서,
제거할 필요는 없음.
